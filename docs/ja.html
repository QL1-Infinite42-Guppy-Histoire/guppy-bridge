詳細

—

ルートと契約アドレスは https://bridge.zaphod.one/api/state（2026-11-07 取得）の写しです。 42 Chain／BSC／Ethereum から送る場合は Zaphod の BridgeRouter を使い、トークンの使用許可のあと、 quoteNative でその場で取り直した中継手数料を上乗せして transferRemote を呼びます。 QL1 から送る場合は BridgeRouter が無いので、Hyperlane のワープルーターへ使用許可をして、 金額 0 で transferRemote を直接呼びます。到着は、受け取り側チェーンの Hyperlane メールボックスの delivered(messageId) と、受け取る人の残高で確認します。

2026-11-07 のライブ確認で無効にしたもの: BNB Smart Chain から送る場合と Ethereum から送る場合 （ブリッジ契約が旧バージョン 1.1.0／1.2.0 で、中継手数料の見積もりがエラーになり、 送る前に手数料を確認できないため。この2チェーンで受け取ることはできます）、および OSAK の 42 Chain → QL1（この向きの送信記録が契約の全履歴で 0 件のため未証明）。 それ以外のルートは、契約のバージョン・停止状態・トークンのアドレス・宛先の許可・ 最小／最大・2種類の見積もりが全てライブで答えることを確認済みです。
