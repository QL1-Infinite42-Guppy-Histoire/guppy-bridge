詳細

—

ルートと契約アドレスは https://bridge.zaphod.one/api/state（2026-11-07 取得）の写しです。 42 Chain／BSC／Ethereum から送る場合は Zaphod の BridgeRouter を使い、トークンの使用許可のあと、 quoteNative でその場で取り直した中継手数料を上乗せして transferRemote を呼びます。 QL1 から送る場合は BridgeRouter が無いので、Hyperlane のワープルーターへ使用許可をして、 金額 0 で transferRemote を直接呼びます。到着は、受け取り側チェーンの Hyperlane メールボックスの delivered(messageId) と、受け取る人の残高で確認します。

手数料無料の直接ルート — 2026-11-07 にテストして終了しました：公式ルーターを通さず、 トークンのワープ契約へ直接送る方法を、実際の 0.1 USDT 送信（42 Chain → BSC）で テストしました。結果は不可でした。ワープ契約は公式の BridgeRouter からの送信しか 受け付けない仕組みのため、送信は必ずそのルーター経由になり、USDT/USDC の手数料（2）が かかります。テストの詳細な記録はプロジェクトの README にあります。

BNB Smart Chain から送る場合と Ethereum から送る場合も使えます。この2チェーンの ブリッジ契約は旧バージョン（1.1.0／1.2.0）で、中継手数料の見積もり呼び出しがエラーに なるため、公式サイト bridge.zaphod.one とまったく同じく、中継手数料 0 で送ります （この向きの到着実績は確認済みです）。 無効にしているルートはありません（全26トークンルートが使えます）。代わりに警告が つくものが1つあります：OSAK の 42 Chain → QL1 は、この向きの送信記録が契約の全履歴で 0 件のため未証明です（選ぶとサイトに表示されます。最初は少額で試してください）。 全ルートとも、契約のバージョン・停止状態・トークンのアドレス・宛先の許可・ 最小／最大・見積もりをライブで確認済みです。
